# Arya A — Portfolio

A responsive personal portfolio for Arya A, an Artificial Intelligence and Machine Learning student at Rajalakshmi Engineering College.

## About the site

The site introduces Arya, highlights selected project ideas, and offers ways to connect through LinkedIn, GitHub, and email. It uses semantic HTML, CSS, and a small amount of JavaScript. There is no build step or dependency installation.

## Featured work

- **TransitPulse:** A city bus booking and capacity management concept developed for Smart India Hackathon 2026.
- **Posture Correcting AI:** A hackathon idea exploring computer vision for posture feedback.

These entries are described as concepts/ideas on the website; they are not presented as finished products.

## Run locally

Open `index.html` in a browser. In VS Code, you can also use a local preview extension such as Live Server.

## Customize

Edit `index.html` to update the biography, project cards, colors, and contact links. The CSS and JavaScript are included in that file so the site is easy to move and host.

## Deployment

This is a static site. It can be hosted with GitHub Pages or any static web host by serving `index.html` from the repository root.
